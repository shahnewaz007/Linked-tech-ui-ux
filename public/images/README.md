# About page team photo

Save the official Linked Technologies team photo here with this exact name:

    public/images/team-photo.jpg

It is used automatically by the About Us page intro section
(`TeamPhoto` in `src/app/App.tsx`). Until the file exists, the page shows a
temporary industrial-team fallback image so nothing looks broken.

Recommended: landscape orientation, at least 1000×700px, optimized JPG.
